# Code of Conduct

## Our standard

We want collaboration that is technically rigorous, candid, welcoming, and respectful of people's
time. Participants are expected to:

- critique ideas and code without attacking people;
- disclose uncertainty, conflicts, and meaningful AI assistance;
- respect consent, privacy, licenses, and maintainer boundaries;
- avoid spam, harassment, discriminatory language, deception, and manufactured engagement;
- accept moderation and review decisions professionally;
- take responsibility for automated actions performed under their identity or credentials.

## Unacceptable behavior

Unacceptable behavior includes harassment, threats, sexualized attention, discriminatory conduct,
doxxing, publishing private communications without permission, evading moderation, impersonation,
and using automation to overwhelm contributors or maintainers.

## Enforcement

Report conduct concerns privately to the project lead through GitHub. For sensitive cases, use a
private security advisory and state that the report concerns conduct so it can be routed correctly.
Maintainers may edit or remove content, lock threads, reject contributions, or temporarily or
permanently restrict participation. Enforcement decisions should be proportionate and protect the
reporter's privacy where possible.

This code applies in project spaces and when someone publicly represents the project.
